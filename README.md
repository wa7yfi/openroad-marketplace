# OpenRoad car marketplace demo

Open `index.html` in a modern browser to try the sample marketplace. No package installation or build step is required. Pushing to `main` deploys the static site to GitHub Pages.

## What you can try

- Browse sample cars and filter by make, model, year, and maximum price.
- Sort the listings and save favorites in this browser.
- Create a demo profile, publish a car listing, and add up to three photos.
- Open a listing and save a demo inquiry.

## Demo limitations

This is a front-end prototype, not a production marketplace. Accounts, listings, favorites, and inquiries are stored locally in the current browser; they are not shared with other users or sent to a server. It does not provide real authentication, messaging, payments, or purchase processing. Do not enter sensitive information.

Sample car photography and fonts are loaded from external image and font services, so those need an internet connection. Seller-uploaded photos must be JPG, PNG, or WebP and no larger than 500 KB each.
